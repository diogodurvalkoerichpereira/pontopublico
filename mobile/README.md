# Empacotamento móvel

O produto é instalável como PWA. Para as lojas, gere os ícones PNG 192/512 a partir de `public/pwa-icon.svg`, valide o manifesto e use um invólucro TWA/Capacitor apontando para a URL HTTPS de produção.

Antes da submissão: informar IDs dos aplicativos, configurar Universal/App Links, VAPID no backend, política de privacidade, screenshots, assinatura Android e certificados/provisionamento iOS. A publicação exige contas e aprovação da Apple e do Google.
